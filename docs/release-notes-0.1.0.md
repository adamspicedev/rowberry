# Rowberry 0.1.0 candidate

Unpublished development candidate under GPL-3.0-only. Signing and platform qualification remain pending.

- Saved PostgreSQL connections with verified TLS and OS vault or session-only passwords.
- Schema navigation, bounded table pages, SQL tabs, cancellation and explicit transactions.
- Local JSON drafts with lossless numbers, worker search, preview and guarded saves to identifiable rows.
- Saved queries and local recovery controls. Internal dbapp profile storage remains stable.

Result pages, SQL, bridge payloads and JSON documents have explicit size limits shown by the application. Arbitrary result sets remain read-only. COPY streaming and automatic updates are unavailable. Inspect unknown query/write outcomes before retrying.

For manual upgrades close Rowberry, back up the application profile following [data storage](data-storage.md), then install the matching architecture's package. Release packages and corresponding source must be distributed with SHA256SUMS. No production download URLs exist yet.
