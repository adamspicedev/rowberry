# Rowberry 0.1.5 candidate

macOS Apple-silicon development candidate.

- Make the JSON discard confirmation usable from the keyboard. Focus starts on **Keep editing JSON**, and the other workspace controls remain inactive while the prompt is open.
- Cancel with Escape or **Keep editing JSON** to retain the draft and return focus to the button that opened the prompt. Discarding still requires choosing **Discard and close JSON**.

The separate Home-key focus issue with VoiceOver active remains unresolved. Final-release acceptance remains pending.
